# Phase 1 & 2 — repository review

## Initial state

- Minimal tree: ad-hoc scripts under `preprocessing/` with **hard-coded `D:/pathosurv-ml` paths**.
- `preprocessing/match_slides.py` had a broken `__main__` block (nested inside a function).
- `data_tools/extract_features.py` ran **dummy ResNet patches** (Phase 6 scope, not validated).
- No `pyproject.toml`, README, manifest registry, or pytest coverage for data artifacts.
- `configs/data.yaml` used absolute Windows paths.

## Issues addressed

| Area | Action |
|------|--------|
